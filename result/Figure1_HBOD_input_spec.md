# Figure 1 Input Specification (HBOD)

Use this exact input set and scales in the manuscript figure:

- Session duration (minutes)
- Session intensity: Borg CR-10 RPE (0-10)
- Hooper wellness items (all 1-7, where 1 is best and 7 is worst):
  - Sleep
  - Stress
  - Soreness
  - Fatigue
- Health module:
  - Daily pain flag (Yes/No) with optional location
  - Weekly OSTRC-H (Q1..Q4, each 0-25)

Do not include non-protocol inputs in Figure 1:

- readiness to train (derived output, not an input)
- hydration/illness (not in current HBOD data model)
- TQR (not in current HBOD data model)

Naming:

- Use HBOD (Hooper-Borg-Oslo-Dergaa) consistently.
- English labels only.
